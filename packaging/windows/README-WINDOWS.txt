OpenKJ Rewired portable Windows bundle

Run run-openkj.bat. It configures the bundled GStreamer plugin path before starting OpenKJ.

This collection includes the application, Qt runtime files, MinGW runtime files, GStreamer runtime and plugins, TagLib/spdlog dependencies, and required support data. It intentionally does not include Microsoft Visual C++ runtime files; this build uses the MSYS2 MinGW toolchain rather than MSVC.

This is a portable test collection, not an installer. Extract the complete directory before running it.
